command, on one line or pasted as a block):

```

(3) OPEN ITEMS in priority order, each with its next concrete command. (4) OWNER DECISIONS, quoted verbatim with dates. (5) DEFECTS found and fixed this session: one line each, with the file and the test that pins it. (6) Anything uncommitted or unpushed. Keep numbers exact; drop narrative, tool output and superseded values (if a number changed, keep only the latest and say what it replaced). Preserve verbatim the standing rules: $0 spend; no terms-of-service bypass (no LinkedIn, Indeed, Handshake, iCIMS, Oracle Cloud HCM, careers.electric.coop); N >= 100; energy/utility/data-center umbrella only; associational-not-causal; a dated pre-registration section 8 amendment for every post-data change, stating whether it helped or hurt; frame additions recorded before the run that collects them; regression tests from real strings, proven with backup copies; clock times only from a clock or commit.
```

