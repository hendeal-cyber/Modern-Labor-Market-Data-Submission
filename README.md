# Determinants of Advertised Pay in the US Energy and Data Center Sector

A regression study of what attributes stated in a job posting predict the pay
an employer advertises, across the United States energy and data center sector.

**Everything here is reproducible from the committed raw snapshots.** No number
in the paper is hand-entered; each is produced by a script from data in this
repository. If a figure in the write-up cannot be regenerated by the commands
below, that is a bug.

---

## What is in the repository

```
config/           what the study CHOOSES: employer frame, scope, mandate
                  states, regressor dictionary
data/raw/         what the study FETCHED: immutable JSON snapshots, one
                  directory per collection run, full posting text
data/analysis/    derived: postings.csv, the selection funnel, model output
docs/             pre-registration, methods, codebook, audit log, limitations,
                  executive summary, token-verification ledger
paper/            the write-up, figures and slide deck
src/lmstudy/      the pipeline
tests/            every suite, offline
```

The distinction between `config/` and `data/` is deliberate: configuration is
reviewable judgement, data is evidence. Neither is hand-edited to fit the other.

## Reproducing the results

```bash
pip install -r requirements.txt

python tests/run_all.py                 # every suite, no network needed
python src/lmstudy/build_dataset.py     # raw snapshots -> postings.csv + funnel
python src/lmstudy/analyze.py           # the four pre-registered models
python scripts/make_figures.py          # figures
python scripts/make_paper.py            # the paper, from analysis output
python scripts/make_codebook.py         # variable definitions
python scripts/make_exec_summary.py     # one-page summary, findings first
```

Steps 2–6 are pure functions of `data/raw/`, and "identically" here means
**byte-identical**, not merely equivalent. Verified 2026-09-22 by cloning the
repository afresh, deleting every derived artifact and rebuilding:

```bash
git clone -b claude/wonderful-tesla-53lgo4 <this repo> /tmp/repro && cd /tmp/repro
rm -f data/analysis/postings.csv data/analysis/analysis.json \
      data/analysis/results.md data/analysis/selection_funnel.json \
      paper/paper.md docs/executive-summary.md
python src/lmstudy/build_dataset.py && python src/lmstudy/analyze.py
python scripts/make_figures.py && python scripts/make_paper.py
python scripts/make_exec_summary.py
diff -r data/analysis paper docs   # against the committed copies
```

`postings.csv`, `analysis.json`, `results.md`, `paper.md` and
`executive-summary.md` all came back byte-for-byte identical — including all
fifteen wild-cluster-bootstrap p-values at 9,999 replications, which is the
point of fixing the seed.

The **one** field that differs is `built_at` in `selection_funnel.json`, which
records when the build ran and is supposed to differ. Nothing else does.

That took one fix to achieve: `analysis.json` recorded the dataset's absolute
path, so a rebuild anywhere but the original directory differed in exactly that
leaf. It is repo-relative now, which is what makes `diff` a usable check rather
than a source of false alarms.

## Collecting new data

Collection runs in GitHub Actions, not locally: the authoring environment
cannot reach any ATS host. Dispatch `.github/workflows/collect.yml`
(input `no_slugs: true`). It collects, rebuilds, re-estimates and commits
`data/`.

The weekly Monday cron accumulates flow. ATS APIs expose only currently open
postings, so there is no historical backfill — the panel grows forward only.

## Where the numbers come from

| Claim | Produced by |
|---|---|
| Selection funnel | `data/analysis/selection_funnel.json` |
| Coefficients, CIs, p-values | `data/analysis/analysis.json` |
| Disclosure contrast | `analysis.json` → `disclosure.by_mandate` |
| Regressor accuracy | `docs/audit-log.md`, rounds 1–3 |
| Which jurisdictions mandate disclosure | `config/pay_mandate_states` in `scope.yaml` |

## Read these first

- **`docs/pre-registration.md`** — the specification, committed before the
  national sample was collected, with dated amendments for every change made
  afterwards and whether it was prompted by seeing results.
- **`docs/limitations.md`** — what this study cannot support. Read it before
  quoting any coefficient.
- **`docs/audit-log.md`** — three rounds of hand-checking against real titles.
  Every round found errors that tests had not.
- **`docs/decision-log.md`** — the full history, oldest first: what each scope
  decision was worth when it was made, every failure including the ones that
  produced confident wrong answers rather than crashes, and the reasoning that
  was later reversed. Historical, not current — where it conflicts with the
  files above, they win.

## Compliance

Collection uses public, unauthenticated ATS APIs: the upstream systems
employers publish through. No authentication, no circumvention, one request per
second per host, descriptive User-Agent.

LinkedIn, Indeed and Handshake are **not** used — each prohibits automated
collection in its terms. iCIMS is likewise excluded, verified by reading its
terms rather than assumed. `docs/methods.md` and `docs/limitations.md` record
the reasoning and what it costs the study.
